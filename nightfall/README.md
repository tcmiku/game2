# 长夜 · NIGHTFALL

《长夜》是一款像素风生存动作游戏，支持单人游玩和最多 4 人联机合作。角色自动攻击，玩家通过走位、拾取经验、选择武器与道具、合成神器，在不断增强的敌群中生存。

[在线游戏](https://nightfall-survivors.hjm616.chatgpt.site)

[浏览器测试页面速查](#浏览器测试页面速查)

## 项目特色

- **35 种武器、6 个武器位**：飞刃、环绕、冰爆、连锁闪电、炮塔、陷阱、锁链、龙卷和双剑等武器独立攻击。
- **25 件神器**：满足武器等级、组合与宝箱条件后合成；双武器合成释放一个武器位，四武器合成释放三个武器位。
- **祈愿庭院**：营地北侧新增相连的小地图，中央始火巨像默认开放并可持续供奉，两侧四座雕像提供永久祝福。
- **营地成长**：守火人提供永久属性强化；药师常驻营地，铁匠在第一次死亡后加入，学者在首次击败首领后加入，各自解锁不同的局内道具。
- **帐篷换装**：8 套像素服装、6 种发型、8 种发色和 6 款面具自由搭配，支持动作预览；保存的外观沿用到营地、战斗和联机。
- **持续生存**：击败首领后战斗继续，后续首领变强；第 30 分钟出现死神。
- **多种敌人**：猎犬、孢囊魔、弩手、召唤祭司、铁甲巨像，以及原有敌群、三阶精英和多技能首领。
- **联机续战**：刷新恢复原角色、短线重连、房主自动接管、固定编号与网络延迟显示。
- **武器战绩**：查看每件武器的伤害、平均每秒伤害（DPS）和击杀排行。
- **可探索战场**：3600 × 2400 的像素地图，散布可破坏木箱、陶罐和补给灯；经验晶石按价值分为绿、蓝、紫、金四色。
- **像素美术**：地图、场景角色、物件、武器与特效由 Python／Canvas 绘制；四位 NPC 的对话立绘使用生图模型。
- **资源加载页面**：图片完成加载与解码、字体就绪后进入游戏，加载失败可重试。

## 本地运行

### 环境要求

- Node.js **22.13.0 或更高版本**，具体要求以 `package.json` 的 `engines` 为准。
- npm。
- 只有重新绘制素材时才需要 Python 3 和 Pillow；仓库已包含游戏使用的图片。

以下命令均在项目根目录，即 `package.json` 所在目录执行。

### 安装依赖并初始化数据库

```sh
npm ci
npm run build
```

首次使用新的本地数据库时，执行迁移以创建房间与成员表：

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_massive_avengers.sql
```

迁移前先构建，是为了生成 `dist/server/wrangler.json`。已有上述数据表的本地数据库无需重复执行这份建表脚本。本地运行数据保存在 `.wrangler/state`。

### 启动开发服务

```sh
npm run dev
```

开发服务默认监听 `0.0.0.0`，端口为 `5173`，支持热更新。本机可打开 `http://localhost:5173`；同一局域网中的手机或其他电脑可打开 `http://<运行项目的电脑局域网 IP>:5173`，例如 `http://192.168.1.100:5173`。实际地址以终端打印的 Network 地址为准；如果系统防火墙提示，请允许 Node.js 接受传入连接。

### 预览生产构建

```sh
npm run build
npm run start
```

`npm run start` 使用 Wrangler 在本地运行生产构建，同样监听 `0.0.0.0`，允许局域网设备通过电脑的局域网 IP 和终端输出的端口访问。联机功能需要已初始化的 D1 数据表；所有玩家需访问同一台电脑上的服务。

## 操作方式

| 操作 | 键盘／鼠标 | 触屏 |
| --- | --- | --- |
| 移动 | `WASD` 或方向键 | 拖动屏幕，使用虚拟摇杆 |
| 营地交互 | 点击目标靠近，或靠近后按 `E`／空格 | 点击传送门、角色或交互按钮 |
| 攻击 | 自动攻击 | 自动攻击 |
| 二刀流主动技 | 合成后左键点击战场或技能按钮 | 点击星光轮舞按钮 |
| 升级选择 | 点击选项，或按 `1`、`2`、`3` | 点击选项 |
| 武器库／神器配方 | `R` 或对应按钮 | 点击对应按钮 |
| 武器伤害排行 | `T` 或 DPS 按钮 | 点击 DPS 按钮 |

在营地武器库中，可以从全部 35 种武器中选择初始武器，再通过中央传送门选择「独自出发」或「与友同行」。

单人模式中，暂停、升级选择和武器库面板会暂停战斗。联机中任一存活玩家进入升级选择时，整个队伍的战斗、敌人技能和弹幕都暂停；全部选完后继续。全员使用同一共享卡池：每名存活玩家提供 3 张候选，2 / 3 / 4 人分别为 6 / 9 / 12 张，每名升级玩家领取一张。已领取的卡片显示领取者，其他人不能再次领取；已选完和幽灵玩家可继续观看。不同颜色的鼠标标记会指向队友正在查看的卡片，手机与桌面按卡片位置对齐。武器位、解锁与满级限制仍各自生效；没有可用升级时提供补给。14 秒后自动领取可用选项，积攒的后续升级在全员完成本轮后再开始。联机中个人打开武器库、DPS 或暂停面板不会暂停其他队员。

## 营地与永久成长

游戏从「余火营地」开始。传送门位于地图中央，带有动态光效；附近的居民和设施提供交互。物品名称与交互提示在角色靠近时显示，NPC 对话气泡会自动消失，具体功能以保留营地背景的侧边交互展开：像素立绘与对白在左，符印选择和消耗在右，手机端自动收为底部面板。

### 旅人帐篷 · 更衣与梳妆

点击营地左侧帐篷或左下「帐篷换装」，主角会自动走近并打开换装界面；也可走到帐篷旁按 `E`／空格。全部外观免费，不影响属性。

服装包括逐月旅装、夜行长衣、曙光轻甲、林间猎装、星术长袍、绯羽披风、霜雪斗篷和樱落和服。发型包括兜帽碎发、利落短发、高束马尾、披肩长发、侧编长辫和齐耳短发，可搭配月银、墨黑、栗棕、麦金、绯红、雾蓝、星紫与樱粉发色。

面具包括月纹面具、绯纹狐面、赤鬼半面、夜鸦面具、星辉眼罩和铁卫面甲。主角默认戴月纹面具，旧穿搭自动补齐这款面具；可在「面具」页切换款式或选择「不戴面具」。面具与发型、发色和服装独立搭配，有对应兜帽与露额发型的完整动作帧，发色不会改变面具颜色。

选择时实时试穿，可切换待机、行走、攻击与朝向。点击「保存外观」才会写入本地营地存档，取消或关闭会放弃本次试穿；「恢复初始」同样需要保存才生效。手机端保留固定保存栏。旧存档保留原有衣物、发型、发色与成长进度；联机出发时携带各自保存的穿搭和面具，快照与房主接管保留当前外观。营地、战斗人物、头像、阴影及受击闪光同步使用当前造型。

素材重绘：`python tools/draw_wardrobe.py`，生成完整动作图集和搭配预览图。专项验证：`node --test tests/appearance.test.mjs tests/assets.test.mjs tests/rendering.test.mjs`。

### 守火人 · 伊蕾

初始营地居民。可以交谈，或进入「塑魂」面板消耗余火提升基础属性。

| 属性 | 每级效果 | 等级上限 |
| --- | --- | --- |
| 生命 | 生命上限 +10 | 5 |
| 力量 | 基础伤害 +8% | 5 |
| 疾行 | 移动速度 +4% | 5 |
| 迅捷 | 攻击速度 +5% | 5 |

新存档拥有 **60 余火**。每项属性的升级费用为 `20 + 15 × 当前等级`，永久属性会在下一次出发时生效。

### 铁匠 · 奥伦

第一次死亡后解锁铁匠，永久解锁营地铁砧，并获得一次性的 **20 余火**奖励。铁匠出售下列道具的解锁资格：购买后，道具才会进入之后对局的升级选择池。

| 道具 | 解锁费用 | 每级局内效果 | 局内等级上限 |
| --- | --- | --- | --- |
| 巨匠纹章 | 40 余火 | 武器大小与范围 +20% | 4 |
| 冷铸齿轮 | 60 余火 | 武器冷却 -8% | 4 |

### 药师 · 莱娅与学者 · 索伦

药师常驻月光花圃，旧存档也会自动加入。首次击败首领后救出学者，学者在返回营地后驻留残卷石台；联机队员各自保留解锁进度。两位居民使用独立的对白气泡、像素场景角色和对话立绘。

| 居民 | 道具 | 解锁费用 | 每级局内效果 | 局内等级上限 |
| --- | --- | --- | --- | --- |
| 药师 | 复苏草 | 35 余火 | 每秒恢复 0.3 生命 | 3 |
| 药师 | 护心叶 | 50 余火 | 受到伤害 -8% | 3 |
| 学者 | 星识残页 | 45 余火 | 获得经验 +15% | 3 |
| 学者 | 回响符 | 40 余火 | 生命补给效果 +30% | 3 |

护心叶也是镜盾进化所需的材料。学者提高的是之后升级池中的道具选择范围，招募不会额外发放余火。

### 死亡、结算与存档

- 单人死亡后返回营地；联机中死亡后进入幽灵模式，全部队员倒下才返回。暂停面板中可点击「返回营地」结束本次出发，按当前战绩结算一次余火；联机时仅自己离开，房主退出后队友可接管继续。出发前可以离开联机大厅。
- 每局只结算一次余火，基础奖励为 `floor(个人击杀数 / 50) + floor(对局秒数 / 60) × 2 + 首领击杀数 × 3`，每局最多 **120 余火**；已有存档余额保留。
- 永久属性、营地居民、设施与道具解锁保留；局内武器、等级与临时道具在新一局重置。
- 存档保存在当前浏览器的 `nightfall-camp-v1` 中；刷新后保留，但不会跨设备同步。
- 联机队员分别使用自己的永久属性和道具解锁进度。

## 战阶、异形与首领

联机根据当前存活且在线的 1–4 人调节新生成敌人的生命、伤害与刷新压力。首领生命倍率为 1 / 1.82 / 2.64 / 3.46，普通怪生命为 1 / 1.48 / 1.96 / 2.44，伤害为 1 / 1.1 / 1.2 / 1.3。已经生成的敌人保留原有属性，断线和复活不会突然重置首领血量。

新增雾灯妖（蓄力扇形弹幕）、蚀月蛛（横移追击与减速蛛网）、空壳镜灵（预示落点后瞬移、六向散射），分别从 80、125、210 秒进入刷怪池。所有普通敌人弹丸仍可被武器抵消。

每五分钟轮换首领：枯枝之王 → 棱镜使骸 → 空环使骸 → 断界使骸。棱镜展开减伤折光壁后沿锁定方向贯射；空环放出有安全缺口的环波并在玩家位置延迟星坠；断界先连续两次蓄力突进，再扇形横扫。危险线、落点和环波缺口直接对应伤害判定，首领弹丸保留不可普遍抵消的规则。低血量时攻击节奏加快。

首领到来前 5 秒显示 EVA 式红黑 EMERGENCY 预警、橙色斜纹与侵入倒计时；首领使用工业警戒分段血条，显示名称、血量百分比、战斗状态与登场人数。五种首领都使用 224×224 原生像素精灵和两种施法姿态，显示高度 340–420，镜头在大首领战斗中兼顾玩家与首领、给手机保留走位空间。首领在场时，普通刷怪冷却变为 5 倍、每批至多 1 只，并暂停额外精英批次。首领死亡后恢复日常刷新。

铁匠处的巨匠纹章、冷铸齿轮、长燃余芯、复刻模具在解锁后仍可继续淬炼，每件最多三级，每级永久提高其局内升级上限 1 级：最终分别达到 7 / 7 / 6 / 5 级。淬炼只扩大可选强化次数，不免费赠送局内等级；各玩家携带自己的工艺，出发时固定，重连与房主接管保留。费用从对应解锁价起，每级增加 45 余火。

## 联机共享经验

联机只有房主维护的 `state.teamXp` 一条队伍经验。任何在线存活队友拾取经验都只入账一次，拾取者的星识残页加成也进入这条共享经验；所有队员看到相同进度和队伍等级。全队在线人数决定需求倍率 `1 + 0.55 × (人数 - 1)`，第一条经验需求分别为 6 / 10 / 13 / 16。升级后基础需求沿用原成长曲线，再按人数计算。

全队同时升级并进入现有共享兵装选牌。超出的经验保留，完成本轮选择后再处理下一次升级。幽灵同步队伍等级，倒下期间的升级奖励在复活后补领；在选牌前倒下也不会丢掉该次奖励。离队、掉线、重连调整人数时保留经验条的比例，不凭空升级、不清空进度。快照、差分传输与房主接管保留共享进度和待领取奖励。单人经验规则保持原有行为。

新增怪物会随生存时间逐步加入敌群，每种怪物都具有独立的像素轮廓、移动动作和攻击预警，也能出现绿、蓝、红三阶精英变体。

| 怪物 | 战斗行为 |
| --- | --- |
| 灰鬃猎犬 | 短暂蓄力后沿预警方向扑击，可以侧移躲避 |
| 孢囊魔 | 投放延迟生效的毒池，死亡时也会留下短暂毒池 |
| 裂骨弩手 | 保持距离并横向移动，瞄准后逐发连射高亮弩箭 |

| 铁甲巨像 | 抗击退的重型敌人，近身蓄力后释放有范围预警的震地攻击 |

- 普通敌群随时间增强，包含追击型近战怪和保持距离射击的远程怪；敌方弹幕使用醒目的暖色表现。
- 普通怪可出现三阶精英：绿色「翠影」、蓝色「苍焰」、红色「赤祸」，生命分别为对应普通怪的 3、7、14 倍，经验为对应普通怪的 **6、12、20 倍**，精英经验晶石不会随机替换为回血。
- 精英守卫首次在 **01:00** 出现，此后每 **45 秒**出现一次，持续至死神阶段前。
- 首领从 **05:00** 开始按 5 分钟周期出现，拥有放射荆棘、延迟地面根刺和预警冲锋；击败后继续当前对局，后续轮次更强。同一时间已有存活首领时，不会额外生成新首领。
- **30:00** 进入死神阶段：死神拥有极高生命、伤害与速度，并免疫减速、冻结和击退。该阶段停止提供升级选择。

当前玩法以生存与死亡结算为主，击败首领或到达 30 分钟都不会直接触发通关胜利。

## 联机合作

1. 在营地选择初始武器，通过传送门打开「与友同行」。
2. 输入昵称并创建房间，将 **6 位房间码**交给其他玩家。
3. 其他玩家在各自浏览器中输入房间码加入，最多 4 人。
4. 房主点击「一同出发」。

房主浏览器负责统一计算战斗、升级与合成；`/api/room` 接口验证房间会话、记录输入并转发状态快照，房间与成员信息保存在 D1。队伍共享经验和选项面板，各自领取升级、装备武器并记录伤害。

优先建立房主与每名队员之间的 WebRTC DataChannel，每 **50 毫秒**发送最新输入与显示快照。数据包不排队重传旧帧；大快照分片，只有完整重组且序号更新的快照才应用。发送缓冲拥塞时丢弃旧发送机会，防止操作被历史数据堵住。直连正常时 HTTP / D1 降为每 **650 毫秒**保存恢复检查点和成员心跳；任一队员直连失败，房主恢复快速检查点同步，该队员使用原 HTTP 通路。浏览器不支持 WebRTC、NAT 限制或直连断开时自动回退，房主变更后清理旧连接并重新握手。默认使用 [Cloudflare 公共 STUN 服务](https://developers.cloudflare.com/realtime/turn/faq/)；未配置 TURN，无法直连的网络使用 HTTP 回退。

HTTP 回退中，队员同步以 **50 毫秒**为目标间隔，房主快照以 **80–160 毫秒**为目标间隔并随延迟适当退让，等待大厅每 650 毫秒同步；请求串行执行，请求耗时计入间隔。移动方向变化、停止与升级选择会优先触发下一次请求。快照使用紧凑的实体列编码。房主首次上传完整状态，之后针对已确认版本传输变化的字段、实体新增与删除；服务器合并为完整状态，保留接管所需的伤害、穿透、命中记录、技能和冷却。队员收到只含显示信息与操作确认的轻量快照，连续版本采用增量下行，重复版本不重复下载。遗漏版本时自动改发完整显示快照；房主的增量基准过期时会被拒绝并补发完整状态，防止错误状态继续传播。旧版完整快照仍兼容。数据库读写合并，普通队员读取显示快照时无需载入整个恢复状态。

四人、180 个敌人与 500 颗经验晶石的本地真实房间回归中，快照上行比完整权威快照减少约 **78%**，单个队员下行减少约 **79%**；这是该测试场景的传输量，具体收益随实体和战斗变化而变化。

战斗计算使用独立于画面刷新率的 **50 Hz 固定步进**；短暂卡顿最多回补 1 秒，避免返回页面时挤压执行大量旧帧。队员即时预测自己的移动，并平滑校正位置；其他玩家、敌人与弹幕使用最多 8 帧快照进行插值，缓冲时长随到达间隔与抖动在 50–500 毫秒内调整，显示时钟平滑追赶，短暂外推最多 120 毫秒。静态物件复用快照数据，减少逐帧复制。移动预测超时依据当前间隔在 350–1200 毫秒内调整，避免较慢网络下反复停止；持续断流仍会停止预测。房主超过 1.8 秒没有成功同步时暂停本地计算，等待确认身份。伤害、升级、拾取和死亡由当前房主判定。

玩家按入队顺序获得 P1–P4 编号，以及翡翠、苍蓝、绯红、琥珀四色服装和脚下标记。大厅、战场昵称和队伍列表使用相同编号与颜色；自己的角色另有「你」和箭头标识，角色靠近时昵称会自动错开。

联机死亡后成为可移动的幽灵，没有可用血量，不会被敌人锁定、受伤、攻击或拾取奖励。存活队友在幽灵周围 **76 游戏单位**内持续停留 **3 秒**即可复活；离开范围会重置进度。复活恢复 **50% 最大生命**，获得 **2 秒保护**，保留装备与等级。所有玩家都倒下时结束对局。第一次个人死亡即解锁铁匠，即使之后被复活也保留解锁。房主退出或失联时，其他队员可以接管当前对局。

刷新页面会使用当前标签页 `sessionStorage` 中的会话恢复原房间、原角色和原对局，不占用新位置。断线保留 **60 秒**恢复窗口；短暂失联会停止旧移动输入，角色和装备仍保留，队伍中显示「重连」。房间码和会话凭证分开处理，凭证不会出现在链接中。

房主主动离开等待大厅时，房主身份交给其他成员；对局中房主关闭页面或失去同步后，约 **4 秒**触发自动接管。服务器以原子比较更新选择唯一房主，并通过接管凭据拦截旧房主的迟到快照。新房主从最近一次保存的完整快照继续，保留武器、神器、精英、Boss 技能、弹幕、升级选择与已处理输入。对局编号保持不变，刷新和接管不会重复结算余火。

成员编号使用固定位置，房主变更不会改动已有角色的颜色与编号。输入包按序号处理；刷新恢复时切换序号区间，旧页面迟到的移动或选择不会覆盖新输入。右上角显示网络往返延迟，网络异常时显示「重连」。

联机采用 HTTP 短轮询，适合休闲合作玩法。网站访问权限由 Sites 配置，玩家需要同时拥有网站访问权限和房间码。

## 武器战绩

按 `T` 或点击 DPS 按钮打开面板，可按伤害或击杀排序：

- **伤害**：累计有效伤害，排除超过敌人剩余生命的过量伤害。
- **DPS**：累计伤害除以该武器从获得到当前时刻的时长；合成前的武器按合成时刻结束计时，分母至少为 1 秒。
- **击杀**：将敌人的最后一击归属到对应玩家与武器。

神器拥有独立统计行，合成前的武器记录仍保留。

## 原创 8bit 配乐

背景音乐由 Web Audio 实时合成，使用原创旋律、方波／三角波声部和噪声打击乐，无外部音乐依赖：

| 场景 | 曲目 | 速度与编排 |
| --- | --- | --- |
| 战斗 | 逐月行军 | 132 BPM，脉冲主旋律、分解和弦、三角波低音与噪声鼓点 |
| 营地 | 余火轻眠 | 72 BPM，柔和三角波旋律、稀疏琶音与延长尾音 |

首次点击或按键后开始播放；营地与战斗之间自动淡入淡出。声音按钮同时控制音乐和音效，页面卸载会停止声音并清理调度器。音符调度有回补上限，切回后台页面不会挤压播放大量过期音符。

需要单独试听文件时，可运行 `node tools/render_music.mjs artifacts/audio`，从同一曲谱导出 8-bit PCM WAV；实时游戏不需要下载音频文件。`tests/browser/music.html` 可在浏览器使用真实 AudioContext 与 OfflineAudioContext 验证两首音轨。

## 像素美术与动画

当前启用的地图、场景角色、物件、武器与特效由 Python／Pillow 和 Canvas 绘制。守火人、铁匠、药师与学者的对话立绘由内置生图模型生成，透明原图保存在 `art/generated/npc-{keeper,smith,herbalist,scholar}.png`，完整提示词与用途说明在 `art/npc-portrait-prompts.json`；这些图片仅用于 NPC 面板。Canvas 先绘制到低分辨率缓冲，再采用最近邻放大，游戏画面保留像素边缘，界面文字保持清晰。

角色具有待机、行走与攻击姿态。武器特效包含施法、飞行、命中和消散阶段，例如飞刃残影、冰晶扩散、分叉闪电、法阵蓄能、炮塔后坐、锁链波动、灵鸦振翅和龙卷旋流。武器特效图集共 **12 类、每类 8 帧**，命中粒子的颜色随武器变化。

特效历史保存在客户端，不参与伤害计算。残影最多 128 条，每条最多 6 个采样点，180 毫秒后过期；视野外减少绘制，队友特效降低不透明度。系统启用「减少动态效果」时，会减少快速残影、闪动与漂浮粒子，并保留攻击和受击信息。联机访客使用平滑的显示时间，避免重复快照重播攻击。

## 界面风格

界面采用墨蓝与旧金配色，以像素切角、月纹刻印和细密材质统一各面板。武器库以图标、名称和攻击方式呈现装备；神器保留配方、效果与宝箱消耗。装饰性英文、重复选择提示和重复等级标识已移除。营地、联机、塑魂、神器与战绩面板保持一致的视觉语言，并适配触屏与减少动态效果设置。主题基础样式位于 `app/nightfall-theme.css`，统一面板与响应式样式位于 `app/interface.css`。武器库只滚动内容区，标题与关闭按钮始终可见；各主要面板的键盘焦点限制在当前交互内。NPC 交互样式位于 `app/npc-panels.css`，通过符印选择、强化前后数值、余火消耗与成功反馈呈现成长，并支持键盘焦点约束、Esc 关闭和小屏幕滚动。

### 联机卡顿回归验证

房主同步直接打包展示数据，减少重复遍历与解包临时对象。固定步长补帧最多运行 5 次，丢弃页面长期挂起后的计算欠账；绘制位置缓存随实体消失回收。实时快照保留窗口覆盖高于 800 毫秒的往返延迟，避免确认到达时基准已被淘汰、从而持续退回完整包；缓存仍有硬性上限。武器抵消弹幕先检查保守包围范围，只对可能接触的攻击执行原有精确检测，保留命中顺序、玩家归属和 Boss 弹幕规则。

`node --test tests/realtime-latency.test.mjs tests/counterfire.test.mjs` 覆盖 900 毫秒往返延迟、确认完全丢失时的缓存上限，以及圆形、圆环、扇形、扫掠线段共 1500 组碰撞对照。`node tools/benchmark-network.mjs` 与 `node tools/benchmark-counterfire.mjs` 可单独测量同步处理、弹幕抵消计算；这些局部耗时不代表整场帧率或公网延迟。


### 阐释者、逐暗者与二刀流

- **阐释者**：黑银剑身、银色刃缘与不对称护手；自动朝近处目标挥出扇形剑光。等级提升伤害与范围。
- **逐暗者**：青碧剑身、深色剑柄与水晶状护手；自动发射可贯穿敌人的远程月牙剑气。等级提升伤害与穿透。
- 两把剑都可在营地武器库选为初始武器，也可在局内升级时获取。阐释者 Lv.3 ＋ 逐暗者 Lv.3 ＋ 宝箱 ×1，在神器页合成 **二刀流**，释放一个武器位。
- **二刀流**同时强化两种攻击：近身剑光伤害 ×1.65、范围 ×1.4，基础间隔从 0.85 秒缩至 0.43 秒；远程剑气变成三重齐发、伤害 ×1.7、穿透 10 次，并提高速度与持续时间。伤害统一记入二刀流。
- 主动技 **星光轮舞**：合成后点击战场鼠标左键，或点击右下技能按钮释放。角色持双剑旋转 **3.5 秒**，范围持续斩击，移动速度 **+65%**，移动留下短暂带伤害的光轨。基础冷却 **12 秒**，从释放时开始，受攻速与冷铸齿轮影响。按钮显示旋风剩余时间与冷却进度；长按或重复网络包不会自动连放。
- 单人暂停与队伍选牌暂停期间，技能持续时间和冷却一同冻结。主动状态、冷却与点击序号进入联机快照，房主接管不会重复释放。减弱动态设置保留范围提示，关闭角色高速旋转与残影。

本地开发服务启动后，可打开 [双剑试炼](http://localhost:5173/tests/browser/dual-swords.html)，切换单剑、合成二刀流、点击左键或技能按钮，使用 WASD 或「移动演示」检查旋风与光轨。「暂停」「步进」「重置」用于逐帧检查。测试页复用生产游戏的战斗模拟、Renderer 和主动技能组件。

素材重绘：`python tools/draw_dual_swords.py`。新增机制测试：`node --test tests/dual-swords.test.mjs`。

### 合成优先显示与 meme之王

局内打开神器页时，满足材料和宝箱条件的神器自动排在最前面，并显示可合成数量；已觉醒神器放到列表最后。面板打开期间若获得宝箱或满足新配方，列表自动回到顶部。收藏页保留收藏范围，也会优先显示其中可合成的配方。

**meme之王**：旋转猫咪 Lv.5 ＋ 咕咕嘎嘎 Lv.5 ＋ 曼波小马 Lv.5 ＋ 香蕉猫 Lv.5 ＋ 宝箱 ×1。四把武器合为一件神器，占一个武器位，释放三个空位；已经用于其他进化的材料不可再次消耗。

每轮攻击同时释放八方回旋猫群、六重大范围冰音波、五列高速星骑和三连香蕉炸弹。猫群返航后可再次命中；音波短暂冻结普通敌人；骑兵留下伤害星轨；落地果皮扩大爆炸范围并连锁引爆，每名玩家至多保留 12 片果皮。基础轮次间隔 2.4 秒，受攻速与冷铸齿轮影响，范围、持续时间和复刻模具继续生效。四种攻击伤害统一记入 meme之王，合成会清理原武器尚在场的攻击。

四材料配方用两行材料显示，准确标注「空位 +3」。可打开 [meme之王与合成试玩](http://localhost:5173/tests/browser/meme-king.html)，使用「获得宝箱」「神器合成」验证置顶与四合一；「延迟获得宝箱」可检查列表已滚动时的自动更新。

图标重绘：`python tools/draw_meme_king.py`。专项验证：`node --test tests/meme-king.test.mjs`。


## 卓耿、飞龙与光之巨人

新增武器「卓耿」是一颗随行龙蛋，锁定目标后直线冲撞、返回主人，未进化时不喷火。卓耿 Lv.3 + 焰瓶 Lv.3 + 一个宝箱可合成「飞龙」，消耗焰瓶释放一个武器位；飞龙具有翼膜、双足、角冠、长尾，自动喷吐扇形龙焰并俯冲抓击。

新增「神光棒」发射穿透光矢；普通增益「光之遗传因子」每级增加 12% 光系伤害，最多三级。神光棒 Lv.1 与因子 Lv.1 同时持有超过 180 秒后，消耗一个宝箱合成「超人力霸王」。计时从两者都获得时开始，只累计角色在线存活且战斗推进的时间；暂停不计，兵装录显示共同持有进度。

超人力霸王通过战场右键或技能按钮变身，维持 15 秒，期间免疫所有敌方伤害，自动发射贯穿光线；左键朝鼠标方向挥出大型重拳，每次按下触发一次，最短间隔 0.45 秒。手机使用变身、重拳按钮，未指定鼠标方向时朝最近目标出拳。变身固定冷却 90 秒，从启动开始计时；攻速和持续时间道具不会延长无敌或缩短该冷却。变身结束恢复原外观，断线取消变身，重新连接不会重置冷却。重复输入和房主接管不会重复释放。

图标新增在 sprite 72–76，武器图集现为 6×11；原有槽位不变。`public/art/pixel-dragon-light.png` 为 128px 单元、6×2 的原生像素动作图集，含龙蛋、飞龙、巨人的共 12 种姿态。只运行 `tools/draw_dragon_light.py` 可重绘本次资源，生成器会核对之前的 56 个图标完全保留。`lib/dragon-light.mjs` 提供房主判定与对应绘制；`components/game/ultra-skill.tsx` 显示剩余无敌时间与冷却。

`node --test tests/dragon-light.test.mjs` 覆盖三分钟边界、冲撞与进化、无敌期限、主动输入去重、出拳方向、联机快照与接管；`node tests/dragon-light.integration.mjs` 使用本地真实四人房间接口检查主动输入、飞龙状态及房主转移。开发预览 `/tests/browser/dragon-light.html` 不读取营地存档，可切换武器、检查共鸣门槛，并通过右键/左键和触屏技能按钮演示。


## 神像专属能力

神像首次唤醒即解锁一项特殊能力，之后供奉继续提升原有永久属性。能力与等级、数值一起在下次出发时固定到角色，联机每位玩家使用自己的神像进度；局内输入不能重写这些解锁。

| 神像 | 专属能力 | 战斗效果 |
| --- | --- | --- |
| 始火巨像（默认 Lv.1） | 始火重燃 | 每局抵挡一次致命伤，恢复 25% 生命并获得 1.5 秒庇护 |
| 破晓剑像 | 破晓剑气 | 命中敌人后射出贯穿剑气，伤害为基础伤害的 2 倍，冷却 6 秒 |
| 长青守像 | 长青藤环 | 受伤后出现 3 秒藤环，减速周围敌人并恢复 12% 生命，冷却 12 秒 |
| 风行旅像 | 风行闪避 | 空格或闪避按钮向当前移动方向突进 156 单位，持续约 0.22 秒并短暂无敌，冷却 2.4 秒；静止时沿上次移动方向，不能穿过场景物件 |
| 星辉祈像 | 星辉齐奏 | 有敌人时每 8 秒发射 3 颗索敌星弹 |

祈福页在现场雕像旁显示「首次唤醒解锁 / 专属能力已解锁」、能力名称与具体用法；移动端保留能力说明、祭器和实际雕像的可见空间。旧存档中已经唤醒的神像自动具备能力，无需重新供奉。旧对局检查点缺少能力记录时沿用原规则，下一局应用存档中的解锁。

`lib/shrine-powers.mjs` 是闪避、保命、藤环、剑气和星弹的房主判定及绘制入口；`dashSeq` 经过 HTTP/RTC 同一清洗器与单次消费校验，`RemoteView` 为闪避即时预测、重放尚未确认的位移，并在障碍、暂停与断线时停止预测。解锁、消耗过的始火庇护、冷却与输入序号均保留在权威快照和接管中；暂停不推进持续时间与冷却，死亡和断线取消闪避与藤环，保命次数不会因复活或接管重置。

`node --test tests/shrine-powers.test.mjs tests/sanctuary.test.mjs tests/network.test.mjs` 覆盖能力门槛、无敌、碰撞、冷却与客机预测；`node tests/shrine-powers.integration.mjs` 检查本地四人真实房间输入与接管。`/tests/browser/shrine-powers.html` 是不读取营地存档的独立试炼，可实际按住祭器解锁、出发并通过空格或手机按钮闪避。
